# Душнила для рабочего стола Ubuntu GNOME

Открой терминал в распакованной папке и выполни **./install.sh**. При первой установке GNOME может обнаружить расширение только при следующем входе в сеанс. После этого нажми ярлык **Душнила** в меню приложений или на рабочем столе. Если рабочий стол предлагает открыть текст ярлыка, выбери в его контекстном меню «Разрешить запуск». Повторное нажатие ярлыка запуска не создаёт второго питомца.

Герой рисуется оболочкой GNOME поверх рабочего стола и обычных приложений. Поддержка в метаданных указана для GNOME Shell 46–50. Целевой выпуск — Ubuntu 26.04 GNOME. Установка выполняется для текущего пользователя без sudo. Файлы спрайтов уже включены.

При кликах Душнила чередует пять авторских фраз и новые колкости. С седьмого нажатия начинает раздражаться. На шестнадцатом вспыхивает и бросается за реальным указателем. Поймав курсор, через шесть секунд отпускает его и засыпает. Отключение расширения также освобождает указатель. Если долго убегать, дед устанет. Уставший герой садится и засыпает. ЛКМ по спящему будит его. ПКМ по герою успокаивает его в любой момент.

Чтобы убрать питомца, выбери «Убрать питомца» в контекстном меню ярлыка в панели приложений или выключи «Душнила» в приложении «Расширения». GNOME запоминает, включён ли питомец, между сеансами.

Выпуск 2. Для обновления выполни ./install.sh из этой папки, затем выйди из сеанса Ubuntu, войди снова и нажми «Душнила». Команда выключения: gnome-extensions disable dushnila@desktop.local.

На каждой второй прогулке Душнила ищет место для сценки. Подвинув значок, он садится на перекур. У ярлыка VS Code или Codex он показывает пальцем, смеётся и говорит «такое еще кто-то использует ?!». ЛКМ прерывает сценку, ПКМ успокаивает героя. Перетащи его на свободное место, если окна закрывают рабочий стол.

Выпуск 5. Душнила меняет местами два ярлыка .desktop, пинает один на свободное место или толкает его на другой монитор. Для перемещения включи ручную расстановку в Desktop Icons NG и открой рабочий стол. Для обмена нужны два ярлыка с сохранёнными позициями. Если DING ещё не сохранил позицию, вручную перетащи ярлык на свободное место. Перенос доступен в режиме расширенного рабочего стола.

Shift + левый щелчок по спокойному питомцу сразу запускает следующую доступную сценку. Эти действия также чередуются во время прогулок. Во время движения питомец показывает анимированную копию иконки. В конце обновляет координаты реальных ярлыков через DING/GVFS. После успешной записи и проверки позиций ставит руки в боки и говорит «так-то получше будет». Рабочий стол может округлить позицию до своей сетки. При отсутствии подходящих ярлыков остаются прежние прогулки и сценки.

Выпуск 4. Через 15 минут после включения, затем каждые 15 минут питомец стучит по стеклу под запись window_knock02 и спрашивает «курить пойдешь ?». Проверка без ожидания — нажми колёсиком мыши на спокойного питомца. Проверка не сдвигает таймер. При погоне или перетаскивании питомец дожидается паузы. Запись проигрывается на обычном аудиовыходе. При ошибке проигрывателя расширение пробует следующий из установленных: pw-play, paplay, aplay, ffplay. Если все недоступны или завершаются с ошибкой, появится уведомление.

В режиме расширенного рабочего стола на третьей прогулке, затем через каждые шесть прогулок Душнила разбегается и прыгает на соседний монитор. Учитывается расположение дисплеев в настройках Ubuntu. При одном экране или дублировании изображения он продолжает обычную прогулку.

Ctrl + ЛКМ по деду переключает сценки по очереди: одиночный пикет, притворный обморок, НЛО. Сами они начинаются в свободные минуты. Во время обморока щёлкни по лежащему деду. ПКМ завершает сценку. Если будить его во время обычного сна, он запомнит число пробуждений даже после перезапуска.

Выпуск 6. При отсутствии доступной цели дед пропускает перестановку. После записи новых позиций расширение кратко создаёт и удаляет собственный временный файл на рабочем столе, чтобы DING получил событие изменения каталога. Проверка читает координаты после паузы. Ошибки записи выводятся в журнал GNOME Shell с пометкой «Душнила».

Выпуск 7. В новом интерактивном Bash набери ssh и пробел в начале команды. Дед достаёт каску, надевает и носит шесть секунд. Установщик добавляет строку подключения в ~/.bashrc. На стандартной клавише пробела Bash посылает локальный сигнал без текста команды. Пользовательские привязки пробела сохраняются. Вставка готовой команды из буфера может пропустить событие. Для проверки звука нажми колёсиком по деду. Громкость ударов в WAV усилена.

Выпуск 8. На десятом обычном клике дед роняет очки, кричит «МАКС!!!!» и идёт на ощупь, вытянув руки. Затем возвращается за очками. Клики во время поиска учитываются для берсерка на шестнадцатом нажатии. Зажми ЛКМ на деде и потяни мышь, чтобы рука в перчатке подхватила его за шиворот. Пока держишь кнопку, дед болтает ногами. Отпусти ЛКМ, чтобы поставить его на рабочий стол. Перетаскивание не прибавляет кликов.

Выпуск 9. После десятого клика дед кричит «МАКС!!!!», идёт на ощупь и возвращается. Он наклоняется за очками, протирает их тряпочкой и надевает со словами «Анттиценности какие-то». В выпуске 10 все реплики появляются только в облачке. Звук воспроизводится только при стуке по экрану.

При переходе в активное окно с заголовком Google Chat дед засовывает руки в карманы и говорит «вот дебилы». Реакция срабатывает один раз за просмотр. Если дед занят, она подождёт, пока окно активно. Расширение смотрит на заголовок активного окна или класс приложения. Вкладка с одним именем собеседника без признака Google Chat в заголовке браузера может остаться незамеченной.

Выпуск 11. SSH срабатывает также при запуске ssh в новом интерактивном Bash, в том числе из истории. Каска рисуется отдельным спрайтом. Для вкладок Firefox и Chromium с одним именем собеседника установи google-chat.user.js из архива через менеджер пользовательских скриптов. Он добавляет метку Google Chat в заголовок только на chat.google.com.

Выпуск 12. Shift + ПКМ по спокойному деду открывает настройки. Также доступна команда gnome-extensions prefs dushnila@desktop.local. Интервал стука отсчитывается заново при его изменении. Общий лимит берсерка (по умолчанию 30 с) начинается с момента вспышки, лимит удержания (6 с) — с захвата. Дед отпускает мышь и засыпает по первому из этих ограничений. Изменения длительности применяются со следующего запуска соответствующего таймера. Отключение действий предотвращает их следующий запуск.

Выпуск 13. Потеряв очки, дед ищет их, разворачивается, спотыкается и падает. Над головой лежащего деда появляется знак DevOps с бегущими по восьмёрке цветами. Когда дед встаёт, знак исчезает. Дед оглядывается, возобновляет поиск, подбирает очки, чистит и надевает их. При SSH дед достаёт синюю каску с фонарём из-за спины и надевает её. В финале появляется облачко «Вперёд в прод!». Обе сцены без озвучки. Для полного просмотра сцены с очками порог берсерка должен быть выше 10 кликов либо берсерк можно выключить.
